Este projeto apresenta um Chatbot Vocacional Inteligente, desenvolvido para auxiliar pessoas de todas as idades na jornada de autoconhecimento e exploração de carreiras. Utilizando uma abordagem conversacional e interativa, nosso chatbot guia você através de uma série de perguntas reflexivas sobre seus interesses, habilidades e valores, culminando em sugestões de áreas e profissões personalizadas.

[Link para o Chatbot Online - GitHub Pages](https://iurassek.github.io/Meu-chatbot-vocacional/chatbot_vocacional.html)  ---

## 🤔 Por que um Chatbot Vocacional?

A escolha de uma carreira é uma das decisões mais importantes da vida, mas também pode ser uma das mais desafiadoras. Muitas vezes, nos sentimos perdidos em meio a tantas opções ou incertos sobre quais são nossos verdadeiros talentos e paixões.

Este chatbot foi criado para:

* **Facilitar o Autoconhecimento:** Ajudar você a refletir sobre quem você é, o que te motiva e no que você é bom.
* **Expandir Horizontes:** Apresentar carreiras e áreas de estudo que talvez você nunca tenha considerado.
* **Tornar o Processo Leve e Acessível:** Oferecer uma ferramenta gratuita, fácil de usar e disponível a qualquer momento.
* **Inspirar a Ação:** Motivar você a pesquisar mais a fundo e dar os próximos passos em direção ao seu futuro profissional.

---

## ✨ Funcionalidades Principais

* **Interface Amigável e Intuitiva:** Design limpo e conversas fáceis de seguir.
* **Fluxo de Conversa Guiado:** Perguntas estruturadas para coletar informações relevantes sobre:
    * Seus Interesses e Hobbies
    * Suas Habilidades e Talentos
    * Seus Valores Profissionais e Pessoais
    * Suas Preferências de Ambiente de Trabalho (em desenvolvimento)
    * Áreas de Desinteresse
* **Simulação de IA Generativa:** Respostas que buscam simular uma conversa natural e adaptativa (atualmente com lógica pré-definida, com potencial para integração com LLMs reais).
* **Sugestões Personalizadas (Simuladas):** Com base nas suas respostas, o chatbot oferece algumas direções de carreira para exploração.
* **Respostas Rápidas:** Botões para facilitar a interação em momentos chave da conversa.
* **Indicador de "Digitando":** Para uma experiência de chat mais realista.
* **Responsivo:** Funciona bem em desktops, tablets e smartphones.

## 🚀 Como Usar

É muito simples!

1.  **Acesse o Chatbot:** Clique no link abaixo para abrir o chatbot diretamente no seu navegador:
    * [**Experimente o Chatbot Vocacional Agora!**](https://iurassek.github.io/Meu-chatbot-vocacional/chatbot_vocacional.html) 2.  **Inicie a Conversa:** Siga as instruções do chatbot e responda às perguntas da forma mais sincera possível.
3.  **Explore as Sugestões:** Ao final, o chatbot apresentará algumas sugestões de carreira. Use-as como ponto de partida para suas próprias pesquisas!

Não é necessário instalar nada!

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web front-end:

* **HTML5:** Para a estrutura da página.
* **Tailwind CSS:** Para estilização rápida, moderna e responsiva.
* **JavaScript (Vanilla JS):** Para toda a lógica do chatbot, interatividade e manipulação do DOM.

**Potencial de Evolução:**
* Integração com APIs de Modelos de Linguagem Grandes (LLMs) como Gemini, OpenAI GPT, etc., para uma verdadeira capacidade generativa e análise de linguagem natural.
* Desenvolvimento de um backend para gerenciamento de dados de usuários (com consentimento) e lógicas mais complexas.
